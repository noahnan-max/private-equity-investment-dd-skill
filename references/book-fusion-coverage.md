# Book Fusion Coverage

Use this to make sure each full DD report absorbs the five local source books at module level.

## Five Lenses

| Lens | Source book | Use in report |
| --- | --- | --- |
| PE decision and terms | Ding Min, `私募股权投资和尽职调查手册` | Investment decision logic, downside protection, valuation negotiation, term-sheet and closing implication. |
| Investment logic triangulation | Qi Wei, `投资尽职调查：投资逻辑、尽调方法、实战案例` | Value/valuation/exit/risk coherence; business-finance-industry triangulation; growth verification. |
| Financial/QoE discipline | Zhou Tao, `财务尽职调查：全流程方法与实务案例` | Understand business before numbers; order-revenue-collection bridge; on-site work; nonfinancial cross-check; forecast challenge. |
| Comprehensive DD taxonomy | Hui Zengqiang / Lu Na, `财务、法律、业务尽职调查全流程实务操作指南` | Full workstream coverage: financial, legal, business, tax, contracts, assets, special DD types, report templates. |
| Classic checklist and archive discipline | Guoming/Sun Peiyuan, `尽职调查白皮书` | Process, method, company history, products, assets, HR, finance, business, legal, contract, litigation, environmental, IP checklists. |

## Module Fusion Map

| Report module | Minimum fusion requirement |
| --- | --- |
| Executive judgment | Ding Min for invest/terms decision; Qi Wei for thesis and what must be true; red flags converted into price/conditions/action. |
| Material boundary and work plan | Hui/Lu and Guoming/Sun for process, material list, scope, limitations, and bottom-paper traceability. |
| Company basics/history | Hui/Lu and Guoming/Sun for entity, capital, history, assets, licenses, approvals, and legal existence. |
| Industry/market | Qi Wei and Ding Min for industry boundary, reachable market, industry logic, adoption drivers, competition, and investability. |
| Product/business model | Qi Wei for product truth and core capability; Hui/Lu for product, technology, operations, contracts, and business process. |
| Customers/revenue/growth | Qi Wei for growth quality; Zhou Tao for order-delivery-invoice-revenue-receivable-collection bridge and customer verification. |
| Operations/supply chain | Hui/Lu and Zhou Tao for procurement, production/service process, capacity, inventory, quality, on-site observations, and supplier/customer checks. |
| Financial/QoE | Zhou Tao as primary; Hui/Lu for financial/tax/internal-control taxonomy; Qi Wei for revised forecast and valuation implication. |
| Legal/tax/compliance | Hui/Lu as primary; Guoming/Sun for classic legal, contract, litigation, environmental, IP, labor checklists. |
| Management/team | Ding Min for founder/incentive/alignment; Qi Wei for execution and forecast credibility; Zhou Tao for interview consistency and external validation. |
| Valuation/return/exit | Ding Min and Qi Wei for method fit, valuation negotiation, return bridge, exit feasibility, and risk-to-term mapping. |
| Red flags | All books: convert findings into stop, pause, reprice, CP, covenant, indemnity, specialist review, or post-investment action. |
| Report writing | Qi Wei for conclusion-first investment memo; Hui/Lu and Zhou Tao for DD report structure and limitations; Guoming/Sun for archive/review discipline. |

## Coverage Audit Before Final

For a full report, answer briefly in working notes or QA:

1. Which source-book lens dominated the conclusion, and why?
2. Which modules used at least two book lenses?
3. Which modules are thin because the materials were missing rather than because the skill skipped them?
4. Are the missing modules converted into a data request list?
5. Are legal/tax/IP/labor/environmental conclusions framed as specialist-verification items unless specialist reports were supplied?
